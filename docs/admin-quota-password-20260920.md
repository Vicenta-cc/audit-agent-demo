# 管理员额度与密码规则 · 2026-09-20

从多用户版本 5873ea7 派生。

- 所有 admin 角色免每日三次任务限制；普通用户仍按北京时间每天三次。
- 服务端在入队事务内读取当前角色，仍检查账号有效性、采集账号归属、单用户未完成任务及资源锁。
- 管理员任务继续记账，降级为普通用户后按当天已使用次数执行限制。
- 额度接口新增 unlimited；管理员 limit、remaining 为 null，前端显示每日任务次数不限。
- 创建用户及重置密码最低 8 位、最高 256 位；既有账号与密码不变。

验证：79 项后端专项、19 项浏览器测试、TypeScript 与 Vite 生产构建通过。
本次无数据库结构迁移，发布沿用现有用户数据库、业务数据、密钥及 Profile。回退目标为带鉴权的 5873ea7，不切回无用户鉴权的旧 R2 环境。
