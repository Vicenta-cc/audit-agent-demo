# 词库采用：由后端绑定快照引用

## 范围

仅修改创建 Agent 中正式词库的读取/保存到草案采用接口。没有修改召回词生成质量要求、模型路由、规则展示采用授权、正式保存授权或启动授权。报告共同账号查询属于另一项工作。

新工具输入：

```json
{"strategy":"resource_ref","resource_ref":"resource-ref:<32位随机标识>"}
```

`read_resource`、`save_resource`、`get_resource_save` 的正式词库结果返回此 `recall_plan`。模型选择资源并传回引用，不再组装运行哈希。可选 `enabled_main_terms` 仍支持选择已有搜索词子集，原有后端子集校验保留。

## 后端约束

- 引用持久化在资源数据库的新增 `lexicon_snapshot_refs` 表，绑定 principal、词库 ID、版本、完整内容哈希、运行哈希及搜索词；同一用户同一版本复用引用。
- 正式词库目前共享读取；引用本身额外绑定当前用户，不是可转赠的权限凭证，也不授予保存或采用规则的权限。其他用户即使知道引用也不能使用；可正常读取共享词库，获取属于自己的引用。
- 词库修改（包括只改说明）、删除、改后又改回，均拒绝旧引用。不存在或其他用户的引用统一返回 `RESOURCE_REF_INVALID`；版本变化返回 `RESOURCE_REF_STALE`，不自动采用最新版。
- 工具解析引用后，在现有草案创建/更新/临时规则采用的资源写入锁内再次核验，封住解析到写入之间的并发修改窗口。
- 保存、引用和保存回执在同一资源事务中写入；重放返回原引用，不重绑定新版。已有工具执行回执仍先重放，避免成功后资源变化造成重复创建。
- 已有草案、确认快照和执行契约继续保存 `existing_lexicon` 和真实运行哈希。旧调用参数兼容，新工具 Schema 不再公布词库 hash 输入。
- 历史保存回执没有引用时不会被悄悄升级；读取对应词库、核对当前内容后获取引用。
- 引用无时间 TTL，资源版本变化即失效；重启不会丢失。数据库迁移为新增表，不删除或重写已有数据。

## Prompt 边界

没有追加 system prompt。仅将原 `RESOURCE_PROMPT` 中两行“模型复制运行哈希”的过期说明替换为新接口说明，并记录在提示词逐行变更清单中；更新相应工具说明。没有删除其他行为约束。
