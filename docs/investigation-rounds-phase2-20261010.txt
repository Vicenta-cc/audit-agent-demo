第二阶段：同一会话多轮调查（本地、默认关闭）

开发基线：61099b5（已确认的回答风格与直出版本）
分支：codex/investigation-rounds-phase2

实现范围
- 在现有 creation 会话中同时提供调查创建/资源编辑及自主报告查询工具。
- list_investigation_rounds 读取持久化的轮次关联；copy_investigation_draft
  将本会话已启动调查的目标、规则和词库配置复制为独立草案。
- 复制不启动任务。编辑、预览、用户确认、任务准入、冻结与执行复用原链路。
- 采集/分析参数仍以确认当时的“采集与分析设置”为准，不绕过设置版本检查。
- 已发布报告按轮次自动加入当前会话资料库。每次问答开始时固定可用报告版本；
  同次问答中工具仍可自由选择这些报告，后续问题可扩大查询范围。
- 轮次由原有已提交创建操作投影，兼容旧成功创建回执；没有第二套轮次状态库。
- 查询旧草案不替换当前待编辑草案。草案与任务读取校验会话归属和所有权。
- 最多 20 轮、同时一个待确认草案；并发创建与提交后丢失回复复用原幂等机制。
- API state 新增 multi_round_enabled 和 rounds；旧 draft_artifact/run 字段继续返回
  最新轮次。没有修改前端，完整浏览器交互属于第三阶段。
