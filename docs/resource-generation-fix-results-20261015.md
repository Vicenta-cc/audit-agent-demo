# 资源生成契约改造：实现与验证

本次在独立工作区 `resource-generation-contract` 实现，基于 `checkpoint/resource-tools-before-generation-fix-20261015`。原 3993/3995 服务源码、运行数据和旧回退标签均未修改；候选为 3997 前端、8997 后端，复用既有 8996 代理。尚未合并或替换默认环境。

## 已改

- 常用 `create_ruleset_proposal` / `create_lexicon_edit` 仅发现 `generation_request`，不再混入完整正文 schema。新增罕用 `import_resource(kind, content)`；导入仍复用原创建命令、权限、回执和版本引用。旧应用接口仍兼容完整 content。局部编辑、保存、采用、草案和启动边界保留。
- 新规则的分类、规则、豁免 ID 与顺序由程序生成。模型仍须提供名称、条件、非空分类及规则、风险、阶段和裁定说明；不补空值放行。合法旧格式的生成输出须先完整校验，再经过同一程序编号过程；原样导入及编辑继续保留已有 ID。
- 同一调用重放原回执。明确未写入的生成失败可在同轮以新调用纠正一次；传输与结构失败共享这一次纠正预算。成功去重、已提交结果恢复、执行未知保护保留；内容拦截不授予重试。生成失败后不能切换导入手工正文绕过保护。并发纠正通过事务串行裁决。
- 生成器不新增默认自动模型调用。DeepSeek 保持 SDK `max_retries=0`，每次生成工具执行只调用一次编写器；模型自行纠正的一次新工具调用仍会增加实际耗时。原 Qwen 专属输入检查恢复未在本轮重写。
- 黑话库明确主题、候选、停用备选、标签全库唯一约束；失败返回准确冲突路径，不删词、不改名、不去重。补齐豁免等安全字段路径、阶段和瞬时故障分类。原始失败正文只在显式私有验收捕获中保存，不写入主模型错误正文。
- 精确兼容已观察到的单层生成调用包裹错误，仍执行原参数和权限校验；不猜业务参数。资源回执增加只含 `edit_id` 的 `read_arguments`，修改继续使用含版本的 `update_arguments`。
