# 民族关系长期试采集：K 规则与启动步骤

这是可选环境，不改变默认单条演示。使用同一份代码、独立数据目录和端口；K 的规则、固定 Prompt 和思考参数随 Git 仓库提供，通过下面的命令登记到使用者自己的数据库，无需拷贝开发机数据库。

当前实现是一轮有限批次：抖音，17 个词，每词最多 20 帖，共最多 340 帖进入审核，每帖最多 1000 条一级评论，不抓次级评论，采集并发 1。内容 ID 在同一任务内去重；同帖被多个关键词找到仍可能产生重复平台请求。实际数量可能不足上限，耗时取决于返回量和外部服务，**不是定时循环采集，也不保证恰好持续 24 小时**。

## 1. 安装并初始化

先按根 README 克隆（包括子模块）并运行 `./scripts/install-demo.sh`。然后在仓库根目录：

```bash
cp demo/ethnic.env.example .env.ethnic.local
# 编辑 .env.ethnic.local，填写自己的 DASHSCOPE_API_KEY，按需配置 ASR。
.venv/bin/python scripts/demo.py init --config .env.ethnic.local
.venv/bin/python scripts/demo.py init-ethnic --config .env.ethnic.local
.venv/bin/python scripts/demo.py check --config .env.ethnic.local
.venv/bin/python scripts/demo.py start --config .env.ethnic.local
```

默认地址：http://127.0.0.1:3168/investigation，API 8168，数据 `data/ethnic`。不要将其指向已运行的 `data/demo` 或其他项目库。端口占用时启动器拒绝接管。

`init-ethnic` 不启动采集、不开启定时器，不调用模型。它通过原生 RuleSet 服务发布固定 K 修订并验证编译，登记词库，保存 `data/ethnic/ethnic-resources.json`，其中包括发布修订 ID、配置哈希和实际思考参数。重复导入不增加版本；同 ID 已有不同内容则拒绝覆盖。这里的“发布”指资源可被任务选择，K 的质量状态仍为试运行候选。

想在单条演示中测试 K，也可对 `.env.demo.local` 执行 `init-ethnic`；该命令只导入资源，不提升抓取数量。

## 2. 登录和创建任务

在 **3168** 的“采集账号”添加并登录自己的抖音账号。若另一环境正使用相同账号，不要同时启动采集。点击“新建调查”，可输入：

> 在抖音创建民族关系公开讨论任务。使用已有词库 ethnic_discussion_recall_v1 的全部 17 个启用词，使用已发布的 ruleset.ethnic-content-review.k-trial.v1，不重新生成规则。每个词最多采集 20 帖、最多研判 340 帖，每帖最多 1000 条一级评论，不抓楼中楼。关注公开内容中的民族攻击、歧视、身份归属及跨民族关系讨论，形成有原文证据的报告。主题命中不等于风险，不推断个人的民族身份。

如果助手提出新建规则，明确要求从已有资源选择 K；不要接受临时生成规则冒充 K。词库与 RuleSet 是两个不同选择。必要时复制 `ethnic-resources.json` 中的完整发布修订 ID 给助手。

**确认前检查预览**：平台为抖音；17 个词；每词 20；总研判 340；评论 1000；所选发布修订是 K。新任务应走 V4 冻结配置。已有的单条任务不会因为更改环境变量自动变批量；不要手改数据库或已有快照。若预览仍显示 1 条或临时规则，先修正方案，不确认执行。

点击确认后，worker 执行采集和审核；对话窗口显示进度、错误和报告，发布后可继续问答。全部 pass 也能生成报告，不能为了展示而保证出现风险结果。

## 3. 保持运行、停止与保留

`start` 是前台监督进程：终端需保持运行。关闭网页不影响任务；Ctrl+C 会停止本次 API、前端和 worker。机器需保持开机、联网和唤醒；macOS 可在另一个终端运行 `caffeinate -i -t 86400` 防止空闲睡眠（不保证合盖、关机或断网后运行）。Linux 可在 tmux 会话中启动并分离会话。不要将系统设置为无限重启 worker。

另一终端检查服务：

```bash
.venv/bin/python scripts/demo.py status --config .env.ethnic.local
```

`status` 检查进程、前后端身份与 A/B 接口，**不是采集健康监控**。任务推进情况需要查看任务页面和 `data/ethnic/startup-logs/`。当前交付没有自动故障诊断、自动修复或定时巡检服务；原开发机 Codex 的跟进任务不会随 GitHub 克隆转移。

单帖审核失败会保存失败原因并跳过，后续帖子继续审核。审核接口鉴权/配置故障或连续三帖接口失败只停止审核，正常抓取仍按已确认的关键词和数量继续；未审核内容保留。部分帖子失败时保留成功结果，但不自动生成完整报告，页面会明确说明。详见 [健壮性审查记录](ROBUSTNESS_REVIEW.md)。

模型文本超时最多补试一次；这是单次调用策略，和整轮任务重启不是同一件事。不要因为单帖审核失败或审核服务停止就手工停止正常抓取。采集本身因故障中断时，先保存任务 ID、阶段、错误和最后进度，排查后最多人工重试一次，若再次失败则停止。遇 verify/captcha/需要人工验证，直接停止本次执行并记录，不绕过验证或自动反复登录。若页面无法停止，用启动终端 Ctrl+C 停止本环境全部进程；重新启动可能恢复待执行队列，应先确认失败状态，不盲目重开。

正常完成后保留 `data/ethnic` 整个目录（包括 outputs、各 SQLite、密钥和 Hermes 数据）与 `.env.ethnic.local`，下次用同一配置启动即可查看原对话、报告和问答。备份前停止服务或使用 SQLite 一致性备份；不要只复制一份 audit_index.sqlite3。不能承诺被中断的外部采集无损续跑。

## 4. K 包的准确含义

- RuleSet：`backend/rulesets/bundles/ethnic_k_v1/ruleset.json`。
- 完整 Prompt：同目录 `prompt-profile.json`、`comment-template.txt`。
- 哈希和思考参数：同目录 `manifest.json`。
- 评论：qwen3.7-plus、thinking=true、6000 输出 token 上限、120 秒超时。
- 融合：qwen3.7-plus、thinking=true、3000 输出 token 上限、120 秒超时。

这些参数只随专用 K 发布修订冻结；普通规则不会自动继承。此次打包没有改动 K 判断标准。K 仍有判定波动，应进行人工抽查；导入成功和服务检查通过不代表整轮效果已验收。

17 词：维汉通婚、维汉婚姻、维汉情侣、维汉夫妻、维族能和汉族结婚吗、维族为什么不和汉族结婚、维族外嫁、维族嫁汉族、汉族娶维族、维族找对象、维族只找本民族、维族家里不同意、维汉父母不同意、维汉孩子、维汉混血、维族血统、维族血脉。它们只用于主题召回，词库行的历史通用等级字段不是审核结论。

两种环境各自有一个前台；3168 不会自动接入 3158。旧 `docs/collection-trial.md` 中的 3148 网关、launchd、Codex 巡检和本机路径只是历史实现，不是本交付的启动步骤。
