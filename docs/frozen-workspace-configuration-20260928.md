# 已启动任务的历史配置展示

任务引用的词库被删除后，历史会话原先仍通过实时资源解析生成确认预览。
词库解析失败会令整个 resolution 为空，连仍存在的审核规则也被显示成
“审核规则待配置”，并出现“当前配置暂时无法继续”。实际执行和报告使用的
冻结快照未受影响。

现在读取已确认草稿的配置预览时，先按账号归属查找其 Run，从
`confirmed_configuration` 恢复规则、搜索词、主页地址及采集参数。
该预览不可再次确认，不产生启动前阻断提示；会话卡片不再查询当前资源选项。
未启动草稿继续实时校验词库、规则、采集账号及设置，确认入口保持原有校验。

本次只改变 v4 已确认配置的读取路径。冻结记录、执行流程、报告、主 system
和关键词生成 prompt 均未修改。原有历史版本限制保持不变。
