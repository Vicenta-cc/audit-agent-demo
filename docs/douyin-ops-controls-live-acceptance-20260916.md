## 验收发现与处理

本轮修复并在同一页面验证：

1. 监控页无自动刷新、详情抽屉持有旧快照：增加非重叠轮询，抽屉从最新任务快照取值。
2. 单独暂停分析时运行任务统计变为 0：统计与任务总状态按仍活跃的独立阶段计算。
3. `pausing` 被显示为“进行中”，`stopped` 被显示为“已暂停”：为暂停中、停止中、已停止、已中断增加明确显示。
4. 恢复后的批次累计数被当作采集数，2 条内容显示为 3：改用唯一 `ingested_count`。
5. 普通监控任务日志暴露本地路径：复用公开日志脱敏投影，原始数据库日志保留；重启后页面验证显示 `[本地路径]`。

未修复、阻止完整通过的问题：

- `pipeline.run` 在 `stream_analyzer.join()` 之后才写采集停止/完成态。采集进程实际退出后，仍显示 pausing，“继续采集”禁用直到分析结束。
- 停止分析时队列为空，停止态确认延迟到采集结束；期间仍显示 stopping，无法独立继续分析。
- 单条长视频采用内容边界停止，ASR/翻译/审核中途没有即时取消；本轮翻译截断后进入拆批，放大了上述状态延迟。

后续应先解开执行器生命周期与阶段状态确认的依赖，并处理恢复时单执行器归属，避免仅提前写状态而启动重复分析线程。修复后重跑同任务暂停/恢复及至少一条完整审核，再验证已完成结果不会重复审核。
