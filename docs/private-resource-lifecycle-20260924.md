# 私有资源生命周期候选版本（2026-09-24）

## 产品边界

- 用户词库、规则仅本人可读取、编辑、保存、删除和引用；管理员身份不自动授予跨用户资源访问权。
- 系统预置模板公共只读，修改时另存为自己的资源。规则“发布”仅代表可执行，不代表公开。
- 会话编辑稿仍按用户及会话隔离；正式资源属于用户，可以在自己的不同会话中复用。
- 已确认任务使用冻结快照。保存任务资源不修改任务、重启采集或重新审核。
- 列表、详情、编辑、删除、发布版本读取、引用解析、创建草案和旧版词库 API 都需后端校验，不能只隐藏 UI。

## 保存路径

编辑稿通过已有保存工具提交；正式资源通过资源管理器更新；任务资源使用
`save_draft_lexicon` / `save_draft_ruleset`。任务保存仅传草案 ID、预期版本和操作 ID，
内容由服务端读取，不让模型复制全文或填写内容哈希。

相同用户、草案版本、资源类型只创建一份正式资源。新操作 ID 的恢复调用也返回已有保存结果。
写入和回执同事务提交。旧资源库保存记录并入统一回执查询，避免已保存却查不到。
过期版本明确拒绝，不自动切换到用户未确认的最新内容。

前端配置抽屉提供直接保存按钮，不依赖模型最后一轮回答。正式词库无需再次保存。
旧版仅有扁平搜索词、缺少结构化词库的任务仍明确拒绝，不能凭空补成新词库。

报告发布后的问答工具仍只读；此候选版本不扩张报告 Agent 的写权限。
此时保存使用配置抽屉按钮。不能将服务层状态覆盖测试解释成发布后聊天保存已通过。

## 历史数据与部署

词库新增 `owner_id`。仅根据成功保存回执确定唯一写入者；读取历史、引用句柄不能证明归属。
无写入者的内置默认词库归 `system`；未知归属或多用户写入冲突维持空归属并隐藏，
不自动归给管理员或当前登录用户。规则保留已有创建者归属。

迁移在资源服务初始化时执行。因此上线必须先停止相关写入进程并备份数据库、配置及代码版本，
在数据库副本检查归属统计和历史资源可见性，再安排部署。不能直接重启生产进行试验。
回滚需要同步恢复匹配的数据库备份；旧代码不执行新私有权限检查，仅回滚代码会重新暴露资源。

卡片编辑内容和长备注不丢失、最终回答失败后恢复检查点。
