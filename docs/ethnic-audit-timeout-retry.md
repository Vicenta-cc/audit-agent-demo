# 审核模型请求超时：一次重试

当前采集分支为评论审核、汇总使用的 Qwen 调用补充了请求级超时重试。直连聊天接口及远程文本推理入口均覆盖。

- `requests.Timeout`（包括连接超时、读取超时）后等待 1 秒，以相同输入、模型参数和单次超时设置补试一次。
- 第二次仍超时，记录重试耗尽并抛出 `QwenTimeoutError`。评论补偿和汇总流程识别该错误，不再叠加新的超时重试。
- HTTP 错误、普通连接错误和输出 JSON/语义问题不触发此请求级重试。已有输出合同校验、漏项补偿属于另一机制，未因本次改动扩展。
- 日志记录重试、成功或耗尽，不输出评论、密钥或原始异常内容。

原有单次超时设置未增加，Prompt、RuleSet 和思考模式未修改。生产 worker 仍暂停；新进程加载本次代码后生效。本次没有恢复任务或发起真实采集、模型调用。

验证：158 个测试和 19 个子测试通过，包括模拟超时后成功、连续两次超时、非超时错误、远程文本入口，以及评论和汇总的上层重试不叠加。使用模拟异常验证，不需要实际等待 120 秒或消耗模型额度。
