## 故障与修复范围

克拉玛依调查已完成两条内容审核并发布报告。首次报告问询期间，候选 API 触发 2 GiB 内存上限，被系统终止；恢复后页面读取再次触发同类故障。worker 和原生产服务仍正常，报告数据保留。

`InvestigationRunProjector.project` 原先对所有非 RUNNING 的地域任务调用 `geographic_resume_blocker`，包括 PUBLISHED。工作台、已发布报告和报告问询授权均经过该投影。该检查会读取、反序列化、重新序列化并校验完整地域执行快照；现场快照约 81 MB。这是明确的不必要内存开销，缺少故障时内存剖析，不能认定是 OOM 的唯一原因。

本补丁仅将 PUBLISHED 与 RUNNING 一起排除恢复快照检查，并强制禁止恢复采集，防止陈旧 Job 状态开放恢复入口。其余状态和真正恢复入口的快照完整性检查保持原样。会话/用户归属、workspace 与 draft/run 关联、已发布版本校验及 WAL-aware 报告快照备份均不修改。
