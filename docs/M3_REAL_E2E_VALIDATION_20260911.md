# 新 M3 真实抖音全流程验收（2026-09-11）

本次使用用户在独立实验环境中登录的抖音账号、真实 Qwen、完整 API 和 worker。主题限定为维汉婚恋讨论中的明确歧视、辱骂、暴力表达及正常表达的豁免边界。每次仅一个搜索主词、最多一帖、最多三条一级评论。

## 隔离与范围

固定入口 `http://127.0.0.1:3178/investigation`，API 8178，代码与运行数据均属于 `xhs-audit-agent-m3-resource-lifecycle-experiment`。操作本实验自己的系统服务、账号、采集代码和数据库，没有操作 K2/3168 的进程、任务、数据库或账号。A/B 归档仍按固定指纹验证；C 不在本次范围。

全部资源操作采用真实多轮自然语言与业务工具；第一项任务通过前端按钮确认，其余通过自然语言确认。报告追问使用实际报告冻结数据。局部模拟测试、真实模型工具测试和真实平台采集分别记录，不互相替代。

## 已验证的资源行为

- 原始调查请求会检查实际搜索词的主题相关性；泛化的“群体攻击”等词不能冒充维汉婚恋召回库。修复后先询问是否生成缺失资源，没有自行启动。
- Qwen 生成六条民族主题规则，修改第六条及豁免边界后，形成真实会话版本；先完整展示，再通过后续明确采用创建草案。
- 临时词库含主词、变体和标签，只有启用主词进入搜索；临时资源未保存时即可创建可确认草案。
- 把两份生成资源保存到正式库 v1 后，已建立草案仍使用自己的临时配置，没有自动替换为正式资源。
- 新会话读取正式资源，修改会话副本，未保存时正式库仍为 v1；保存回原处后两份资源均为 v2，再读取核对。
- 主词“维汉通婚”改为“维汉夫妻”后，词条 ID、原变体“维汉婚恋”、标签和启用状态保持不变。若试图把主词改成已有变体同名词，系统拒绝冲突并询问处理意见，没有自行删除变体。
- 修改规则只改变第六条的裁决说明，前五条和全部豁免保持相同。此前已确认的任务仍使用旧快照。

## 实测中发现并修复的问题

| 问题 | 处理与复验 |
| --- | --- |
| 仅按风险领域选择词库，搜索词与调查主题无关 | 提示词明确检查实际主词相关性；同一原始请求复验会先询问是否生成缺失词库 |
| 独立采集代码漏拷贝 cache Python 包，首个混用任务启动失败 | 只补齐本实验采集器的源码；初始化脚本保留该包，启动检查实际导入 DouyinCrawler；后续真实采集验证 |
| 临时词库编辑编号误填为正式来源，纠正时又触发重复请求保护 | 在写入回执之前执行参数校验，修正后可以安全重试；保留原有防重复及版本保护 |
| 模型抄漏展示编号，重新读取后又没有形成可采用的公开展示记录 | 真实 Hermes 中间件为对话中的规则读取记录展示回执；读取、展示完成、后续采用均验证。普通只读 API 保持兼容 |
| 成功的资源回答含内部字段，被前端整段显示为保存失败 | 保留成功解释和业务内容，过滤内部诊断行 |
| 普通对话中的保存表格显示为 Markdown 原文 | 复用支持表格的统一渲染组件，真实页面刷新核对 |
| 旧生成提示仍声称不支持保存 | 修正为通过保存工具完成正式保存，且保存不代表采用或执行 |

另有一次 Qwen `data_inspection_failed` 拒绝，未产生资源或任务。本次保留失败记录，前端明确区分模型内容检查拒绝和存储失败；没有将其算作成功。后来独立生成场景使用抽象专业的审核条件完成生成。外部服务的拒绝风险仍存在，不能承诺每次模型调用都成功。

## 规则质量与结论边界

六条生成规则包含：群体负面泛化、民族身份关联侮辱、非人化及集体犯罪污名、通婚群体排斥、血统污染主张、明确现实暴力威胁；包含正常文化、个人婚恋自主选择和批判性引用的豁免，并明确独立攻击不被豁免覆盖。

真实样本已覆盖反驳自身遭受辱骂的批判性引用、正常婚恋生活分享和普通评论互动。报告问答区分帖子与评论，使用已采集评论数量，保留不可泛化到平台、账号或群体的范围限制。实验内导入的原 K2 规则内容指纹保持不变。

这些是流程与有限样本的行为证据，不是民族风险识别准确率评测；没有足量明确攻击、暴力及少数民族语言阳性样本，不能声称召回率或误报率已达到生产要求。模型抄错长编号仍可能需要重新展示后再采用，本次没有放宽版本或确认校验来换取通过。

## 前端与持久化

固定入口正常展示 A/B 和新增报告。完整报告、报告问答、任务进度、正式版本以及保存回执均在现有页面查看；未增加资源编辑面板。前端源码变更经类型检查和生产构建，实验服务只在无活跃任务/问答时重启；重新打开能恢复同一批报告与会话。

截图及机器汇总位于 `docs/evidence/m3-real-e2e/`。原始逐轮请求、回复、资源快照与失败记录保留在 Git 忽略的 `outputs/m3-real-e2e-20260911/`，不提交密钥、账号登录状态或完整运行数据库。

## 响应时间口径

资源对话时间为后台接受请求到完成持久回答，包含模型思考、工具和多次模型调用；不等于浏览器首字。采集报告时间从确认入队到发布，包含排队、采集、媒体处理与审核。实际截图验证渲染，但本轮不对 DOM 首次绘制给出精确毫秒结论。

本轮功能路径不同，不能用它们代替新旧配对性能实验。此前小样本同请求对照见 `M3_FLOW_AND_LATENCY_VALIDATION_20260911.md`：新版准备草案约增加 2.52 秒、生成三条规则约增加 9.11 秒；这是较早版本的观察值，不是本次最终版本的稳定退化比例。
