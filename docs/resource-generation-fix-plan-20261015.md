# 资源生成契约修复实验

基线：`checkpoint/resource-tools-before-generation-fix-20261015`。本工作区独立验证，不改运行中的 P1 服务。

目标：减少格式和状态协调错误，保留生成、完整内容导入、编辑、保存、展示采用和精确版本引用。正常及失败生成默认均只执行一次模型请求，不增加默认自动重生成。

先补回归用例，再分三处改动：

1. 失败恢复：同调用重放；明确无写入的生成失败可在同轮纠正一次；成功、已提交、执行未知保持去重；拒绝借手工 content 绕过失败。
2. 生成契约：生成与完整导入分别发现；规则编写器只生成业务字段，后端构造新资源 ID 和顺序；词库明确全库唯一性且返回冲突位置，不静默删改。
3. 调用与诊断：只适配无歧义的桥接包裹错误；明确读取参数；保留安全字段路径、阶段、错误类型和请求摘要，不把原始失败正文送入主模型历史。

验证：先定向单测（次数、幂等、提交恢复、完整导入、精确词表、语义必填字段），再资源/草案相关回归。条件允许时在独立端口与数据库运行冻结用例，分别记录首次成功、纠错次数、模型调用数和总耗时；少量样本不作为提速结论。

## 后续小修：读取目录说明

本轮仅调整两个读取工具的说明位置：正式资源的必填 kind、资源 ID 与版本 ID 的区别，以及编辑稿仅传 edit_id 的限制，均须在延迟发现目录截取的首行 60 字符内可见。移除编辑稿说明的重复前缀，完整说明保留 read_arguments 用法、后续局部修改及版本边界。

先用最终发现定义的目录可见前缀补回归并确认旧实现失败，再调整说明，运行发现、读取与资源生命周期相关测试。工具数量、schema、发现机制、生成及串行执行方式均保持原样；本轮不追加真实模型调用，说明改善是否减少重试仍待真实对照验证。
