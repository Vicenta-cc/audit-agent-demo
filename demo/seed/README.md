# A/B 历史演示数据包

此包用于复现既有 A/B 报告与可追溯问答。它是**按报告范围裁剪的历史公开证据包，不是匿名合成数据**。保留历史公开帖文、评论、昵称及稳定身份/引用关系，以便问答中的报告、帖子、评论、账号记录能够一致校验。历史风险标签只是当时模型结果，不表示对现实人物的最终认定。

| 文件 | 内容 |
| --- | --- |
| `report-a.sqlite3.gz` | A 唯一已发布版本及其 201 帖快照、证据、分类与账号投影 |
| `report-b.sqlite3.gz` | B 唯一已发布版本及其 304 帖快照、证据、分类与账号投影 |
| `account_m22_corpus.json.gz` | A/B 问答所需的冻结账号出现记录、公开评论和可核对的直接互动关系 |
| `manifest.json` | 压缩文件、解压数据库、报告正文与快照 SHA-256 |

数据库仅包含原生历史报告导入器需要的 15 张报告表；不包含采集登录账号表、加密登录态、模型 Key、会话聊天、任务队列或其他正式采集运行。初始化后的账号列表为空，使用者须登录自己的平台账号。初始化不重新审核历史样本，也不生成新报告。

部分冻结快照保留原始采集路径作为历史来源元数据，运行时不会读取原开发者的目录。媒体原文件不在此包中；历史公开媒体链接可能过期，但冻结文本、判断、统计和证据查询可本地复现。新任务下载的媒体保存在使用者自己的数据目录。

维护者可用 `scripts/export_demo_seed.py --help` 从指定 A/B 档案重新导出。导出按原 `rowid` 保持快照顺序，不改风险判断或证据内容。更换内容后必须重新生成 manifest 并通过报告校验，不能随意编辑哈希或将校验失败的材料标为通过。

不要把整个生产 `data/` 或 `outputs/` 提交来更新这个包。运行日志和账号 Key 不属于演示资源。
