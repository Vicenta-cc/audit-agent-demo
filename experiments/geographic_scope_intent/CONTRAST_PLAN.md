## 1. 要回答的问题与已有依据

问题是：完整资源与草案流程是否使模型在已识别用户地域要求后，没有把地域约束写入实验草案？需要同时观察地域理解和草案配置，不能把没有创建草案直接解释为没有理解地域。

历史冻结版本为 `geo-intent-p0-real-v2`，HEAD 为 `a4997d3969beab3d499a218e7a7aee025fea46d9`，分支为 `codex/geographic-relevance-p0`。本次检查的 21 个冻结文件哈希全部一致，没有通过刷新快照消除差异。实验文件及测试仍是已有未跟踪文件，保留他人修改。

历史 dev-v2 的合法 set 完成率为 3/5；holdout 原自动判分为 3/6，逐例离线复核为 4/6。`adoption-temp-later` 曾明确提及此前的地域限定，却创建没有地域约束的模拟草案。这支持流程耦合假设，但还没有同模型、同样本的配对对照，不能据此确定因果。原始证据和自动／复核差异见 `REPORT.md` 与 `evidence/real-semantic-summary.json`。

资源适配、采用确认有合理业务含义。本对照不要求模型跳过这些条件；资源未齐备时，应仍能记录地域意图，同时延后草案操作。

## 4. 判分先分开地域意图和草案就绪状态

原 `defer` 表示流程尚不能建草案，不等于没有地域要求。例如“调查乌鲁木齐欠薪，先帮我准备规则和词库”应记录地域 set，同时保持资源／草案延期。

新建旁路标注，不修改原 `cases.jsonl` 或历史分数：

1. **地域轴**：set／clear／keep／clarify／no_task，加目标、策略与有效来源；范围明确而资源不足的样本仍属于 set。
2. **流程轴**：按现有合成资源及采用状态记录草案操作可执行、需延期或不适用。资源覆盖适配疑问另外记录，不把合理延期自动判成地域漏识别。

原 dev 有 5 条 set、2 条 defer；若逐例标注确认后两条都有明确地域要求，地域轴 set 分母为 7，完整草案 set 的原分母仍为 5。必须在调用前冻结最终分母，不根据模型响应调整标签。

必须分别报告：

- **地域理解／记录**：动作准确率、目标／策略／来源正确率，set 精确率和召回率及完整分子／分母，误设、误清、歧义猜测、遗漏、未表达／无法观察。A 的自然语言判读和 B/C 的结构化记录分列，不能把不同出口的得分差直接当理解能力差。
- **草案落地（仅 A/B）**：实际 `relevance_scope_change`、模拟回执、配置保留、原流程完成分数；资源延期时不要求非法建草案。C 无此流程，记“不适用”，不能与 A 的完整流程通过率直接相减。
- **衔接断点**：B 中记录正确但草案漏设的数量／分母；记录错误、合理资源延期、重复确认、达到循环上限、接口／fixture 失败分别归类。
- **边界与运行**：全部固定关键反例的误设／误清，来源越界、真实执行尝试或虚假执行声明；样本数、HTTP 请求数、完成响应数、失败数、工具请求数、耗时和可得 usage。失败案例留在预定案例分母中，precision 无预测时写 0/0、未定义。

逐例保留输入、响应、参数和模拟回执，以人工判读口径离线复核全部 54 次运行。不用被测模型或额外供应商模型替代复核；实施会话复核与原会话真人验收分开。原完整流程判分器保留原判分；正常模拟／否定表达的误判同时报告原判和离线修订判，不覆盖原响应或通过追加调用替换。

## 6. 结论如何解释

- B 正确记录地域、却没有写入本应可执行的草案：支持“识别后到草案配置的衔接有问题”，重点定位资源采用、配置参数和过度确认。
- C 正确而 A/B 没有正确表达／记录：支持完整流程负担影响表现，但仍可能来自提示、任务要求、工具组合或随机性，不能仅说工具数量太多。
- B 同时改善记录和草案落地：支持独立出口与明确记录要求有帮助；不是正式业务接入结论。
- 三组同样出错：不能把原因归给资源／草案耦合，需要保留地域规则、模型能力、数据标注或实验契约的其他解释。
- B/C 记录正确而 A 没有表达：A 的内在理解仍不可观察，不能直接称“资源工具使模型不理解”。

原 34 条全部是合成对话且已用于此前评测。本次 18 条属于复用诊断集；剩余 16 条若以后使用，也不能重新称独立 holdout。单次配对对照存在模型随机性，数据量不足以宣称生产稳定或通过 95% 总方案门槛。
