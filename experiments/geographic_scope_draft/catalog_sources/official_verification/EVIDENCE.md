## 结论及证据强度

使用“2016 年官方完整代码表 + 已核验的后续地级变更”建立独立身份基准，与候选名录逐条比较 `code/name/level/kind/province_code`。34 个省级、333 个真实地级行政区，共 367 条完全相符：无遗漏、额外或身份差异。333 个地级中含 293 个地级市、30 个自治州、7 个地区、3 个盟。按用户最新城市限定决定，P1 支持 293 地级市 + 4 直辖市 = 297 个城市；省级全集保留供归属核验，普通省级与其余地级类型不作调查目标。匹配数量不能替代每条对账，逐条结果见 `comparison_report.json`。

本核验**不是 2026 年民政部全国完整原始名录**，也未把 2016 表格标作 2026 生效。民政部全国列表页面本次仍不可访问。上游固定快照是主要数据来源；历史官方全表与已验证变更是独立交叉核验基准；2024 年末官方统计总数提供额外数量印证。没有发现新的地级身份差异，有限搜索未返回新变更不构成“证明全国截至今天绝无变更”。县级辅助记录没有全部经官方逐条核验，不能宣称县级完整覆盖或将县级提升为 P1 可支持地域。

## 离线复现和文件保真

运行：

```sh
python3 experiments/geographic_scope_draft/catalog_sources/official_verification/reproduce_verification.py
```

脚本只读保存的 web 抽取文本及 `../cn_division/normalized.json`，输出省级基准、完整省/地级基准与逐条差异报告，不联网。原始上游数据、许可证与固定 commit 由 `../cn_division/` 保存。

本机 urllib/curl 对若干官方站点 HTTPS 连接失败，未关闭 TLS 校验。`*_web_*extract.json` 明确标识为工具抽取或搜索抽取，不是 HTTP 原始 HTML/PDF。`urls.json` 是尝试下载的 URL 记录，文件不存在表示未下载成功。`SHA256.json` 计算本目录所有其他文件的字节哈希，用于后续交接检查。
