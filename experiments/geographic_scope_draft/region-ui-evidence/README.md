# 地域编辑区 UI 调整

2026-10-15，P1 工作树。按用户截图调整地域编辑区。

- 当前地域、图标与修改入口放在同一标题区域，策略与执行提示使用次要文字。
- 编辑表单采用浅灰底独立面板，限制输入行最大宽度；保存和取消按钮使用统一样式。
- 普通修改显示“修改调查地域”；仅待澄清状态显示原问题和候选，避免把已解析的北京市再次表述为歧义。
- 小屏输入与操作分行，保留键盘焦点、字段说明、错误、保存中与禁用状态。

实现：`RelevanceScopeEditor.tsx`、`investigation-workspace.css`；现有地域测试增加普通修改不显示歧义问题的断言。设计约定记录在仓库 `DESIGN.md`。

验证：地域交互回归 37 例通过（20.9s）、类型检查与构建通过，`git diff --check` 通过；真实页面查看收起/展开状态，并检查 390px 与 1440px 布局。输入行宽屏最大 720px，候选、验证保存、取消、历史恢复保持原协议。构建保留现有包体大小提示。
